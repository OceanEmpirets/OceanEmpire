# Ocean Empire Releases

This public repository contains Ocean Empire release installers and update metadata.

The game source code and development workflows are kept in the private
[`OceanEmpire-Development`](https://github.com/OceanEmpirets/OceanEmpire-Development)
repository.

Use the GitHub Releases page for downloads. `latest.json` is the public machine-readable
release manifest used by distribution tooling.
